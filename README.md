# Pocket Daydream Login

An original mobile-first React login concept with a character who reacts to the active field:

- Email focus triggers a thinking pose and animated message cloud.
- Password focus makes her cover her eyes.
- After a short pause while typing, she sneaks a quick one-eye peek and covers again.
- Showing the password keeps the playful peek pose in sync with the real input state.
- Friendly validation, loading hearts, success sparkles, keyboard focus, reduced-motion support, and responsive phone layouts are included.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build:

```bash
npm run build
```

## Notes

This is a front-end prototype. Login and social actions are intentionally simulated; connect the form handlers to your authentication provider when you are ready to use real accounts.
